# Manan Wason · Portfolio

Static site for GitHub Pages. `index.html` is the whole site; `Manan_Wason_CV.pdf` is the CV behind the Download CV buttons.

## Publish
1. Create a new public repository on GitHub named `mananwason.github.io` (gives the address https://mananwason.github.io) — or any name, e.g. `portfolio` (gives https://mananwason.github.io/portfolio).
2. Upload `index.html`, `Manan_Wason_CV.pdf` and `.nojekyll` to the repository root (Add file → Upload files → Commit).
3. Settings → Pages → Build and deployment → Source: "Deploy from a branch", Branch: `main`, folder `/ (root)` → Save.
4. Wait a minute or two; the address appears at the top of the Pages settings.

## Update later
Replace `index.html` (or the PDF) with a new version and commit; the site redeploys automatically.
